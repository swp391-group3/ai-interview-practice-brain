# Administration & Platform Governance Domain

## 1. Administrator Capabilities
- **Candidate Management:** View registered candidates, lock/unlock accounts.
- **Session Monitoring:** Inspect active, completed, or interrupted interview sessions.
- **Taxonomy & Domain Management:** Configure technical domains, technologies, and question templates.
- **Avatar & Voice Catalog:** Manage supported 3D models and voice styles.
- **Analytics & Revenue:** View interview statistics, common candidate weaknesses, and transaction reports.

## 2. Implementation State
- Next.js route shell created in `frontend/src/app/admin/`.
- Backend admin handlers to be implemented following core candidate workflows.
