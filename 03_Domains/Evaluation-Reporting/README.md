# Post-Interview AI Evaluation & Reporting Domain

## 1. Domain Objective
Generate comprehensive post-interview feedback and analytics evaluating candidate performance against the target Job Description.

## 2. Evaluation Dimensions (5 Core Competencies)
1. **Technical Accuracy:** Correctness of technical concepts, algorithms, and code logic.
2. **Depth of Understanding:** Ability to explain underlying mechanisms, trade-offs, and edge cases.
3. **Problem-Solving & Approach:** Systematic thinking, structured reasoning, and handling constraints.
4. **Answer Relevance:** Direct alignment with the specific question and target JD requirements.
5. **Communication Clarity:** Conciseness, structure, and articulation of technical ideas.

## 3. Reporting Artifacts
- Overall numerical score (0-100).
- Radar chart comparing performance across technical domains.
- Question-by-question breakdown with model answers and knowledge gap analysis.
- Personalized study roadmap and recommendations.
