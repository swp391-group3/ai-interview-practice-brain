# Brain Inbox

> **Purpose:** Rapid triage folder for incoming unorganized notes, meeting snippets, Discord pasteboards, links, or lecturer remarks before they are classified into Contracts, Decisions, Domains, or Execution queues.

---

## Processing Routine
1. Paste raw context or notes into a scratch file here.
2. Evaluate against the [[Source-of-Truth]] authority model.
3. Move or synthesize into the appropriate domain, ADR, or Jira note.
4. Keep the inbox empty or near-empty.
